# 한글 쓰기 엔진 v0.4

화면 없이 계산만 하는 한글 손글씨 채점 엔진입니다. 어느 앱에 붙여도 디자인은 그 앱이 정하고, 채점은 같은 규칙으로 합니다.

## 범위 (v0.4)
- 기본 자음 14자 (ㄱ~ㅎ), 모음 21자 (ㅏ~ㅣ, 겹모음 포함)
- 채점 항목: **획순 10 · 방향 5 · 모양 75 · 자리·크기 10** (합 100). 모양은 가로·세로 비율 차이를 대부분 봐주고, 평균에 가장 못 쓴 획을 1/4 섞음
- 점수 상한
  - 다른 글자를 쓰면 최고 39점(F)
  - 획이 닿아 멈출 곳(접점)을 넘어가면 넘어간 길이에 따라 최고 40~100점(칸의 4%까지 봐줌, 12% 이상이면 40점)
  - 획이 닿아야 할 곳에 안 닿으면 떨어진 거리에 따라 최고 50~100점(칸의 8%까지 봐줌)
  - 획순이 틀리면 최고 69점(C)
  - 획을 나눠 쓰면(꺾이는 곳에서 펜을 뗐다 이어 씀) 최고 72점, 이어 쓰면 1번 이을 때 60점·2번 이상 40점
  - 흔히 쓰는 다른 꼴(ㅈ·ㅊ을 'ㅡ+ㅅ'로)은 알아보되 최고 65점
  - 방향이 틀리면 최고 79점(B)
- 기기별 허용 폭: `finger`(손가락) · `pen`(펜, 손가락과 같음) · `board`(전자칠판, 더 너그러움)
- 실수로 찍힌 점(칸의 2%보다 짧은 획)은 무시
- 교사 채점 표본 60개 중 57개 기준 평균 차이 4.6점(3개는 교사 확인 후 예외 표시)

## 파일
| 파일 | 하는 일 |
|---|---|
| `src/strokes-consonants.js` | 자음별 획 데이터(순서·방향·위치, 칸 기준 0~1 좌표) |
| `src/strokes-vowels.js` | 모음별 획 데이터 |
| `src/engine.js` | 채점 엔진 `evaluate`, 획 하나 즉시 확인 `checkStroke` |
| `src/feedback-ko.js` | 채점 결과를 학생용 한국어 문장으로 |
| `demo/` | 엔진 확인용 연습 화면, 글씨 채점실(`dev.html`), 서버 연결(`server.js`) |
| `test/engine.test.js` | 골든 테스트 |
| `tools/export-features.mjs` | 표본마다 엔진 측정값·교사 점수·교사가 고른 문제를 CSV 한 줄로 (`npm run features > features.csv`) |
| `test/samples/` | 교사가 점수를 매긴 실제 글씨 표본. 연습 화면에서 모아 내려받은 파일을 넣는다(평균 차이 8점 이하, 하나하나 15점 이하) |

## 쓰는 법
```js
import { evaluate, checkStroke, listChars } from './src/engine.js';
import { feedbackKo } from './src/feedback-ko.js';

listChars('vowel'); // ['ㅏ', 'ㅑ', ...]  'consonant' 또는 생략(전체)

// strokes: [[{x,y}, ...], ...]  쓰기 칸 기준 0~1 좌표
const r = evaluate('ㄷ', strokes, { device: 'finger' });
r.score;        // 0~100
r.grade;        // S A B C F
r.parts;        // { order, direction, shape, placement } 각 0~1
r.issues;       // [{ code: 'WRONG_ORDER', ... }, ...]
r.measures;     // 상한·배점 적용 전 날 측정값(넘어간 길이, 크기 비율, 획별 모양 등). 점수 보정 학습용
feedbackKo(r);  // ['획 순서가 달라요. ...']

// 획순 지키기 모드: 획 하나를 그을 때마다
checkStroke('ㄷ', 0, stroke); // { ok, wrongOrder, wrongDirection, bestIndex }
```

문제 코드: `WRONG_CHAR` `OVERSHOOT` `GAP` `STROKES_JOINED` `STROKE_SPLIT` `ALT_FORM` `EMPTY` `MISSING_STROKE` `EXTRA_STROKE` `WRONG_ORDER` `WRONG_DIRECTION` `TOO_SMALL` `TOO_BIG` `OFF_CENTER` `SHAPE`

## 확인
```bash
npm test
```
```bash
python3 tools/serve.py
```
그다음 맥북에서는 http://localhost:5178/demo/ 를 엽니다.

### 아이패드(펜슬)에서 쓰고 검수하기
1. 맥북과 아이패드를 같은 와이파이에 연결하고, 맥북에서 위 명령을 실행합니다. 화면에 아이패드용 주소(`http://192.168.x.x:5178/demo/`)가 나옵니다.
   학교 와이파이는 기기끼리 통신을 막아 두는 경우가 많아, 안 되면 집 와이파이나 휴대폰 핫스팟을 씁니다.
2. 아이패드 사파리에서 그 주소를 엽니다. 검수표는 `.../demo/review.html` 입니다.
3. 연습 화면에서 '펜슬만 받기'를 켜면 손바닥 터치가 획으로 들어가지 않습니다(설정은 아이패드에 기억됨).
4. 결과 보내기: '검수 결과 복사' 또는 '표본 복사'를 누른 뒤, 같은 Apple ID 맥북에서 붙여 넣습니다(유니버설 클립보드).
   자동 복사가 막히면 글이 담긴 창이 뜨니 길게 눌러 전체 선택 → 복사합니다. 표본은 '표본 내려받기' 후 AirDrop으로 보내도 됩니다.
5. 아이패드에 저장된 검수 표시와 표본은 아이패드 브라우저에만 있습니다(맥북과 따로).

## 채점 보정 표본 모으기
1. 연습 화면에서 글씨를 쓰고 '다 썼어요'를 누릅니다.
2. 결과 아래 '선생님이 본 점수'에 0~100점을 넣고, '선생님 눈에 보이는 문제'를 고른 뒤(문제가 없으면 '문제 없음') '표본 저장'을 누릅니다. 글씨 좌표와 점수, 고른 문제만 저장되며 이름 같은 개인정보는 받지 않습니다.
   - 엔진 결과를 보지 말고 보이는 대로 고릅니다. 이 표시로 엔진 피드백이 맞는지 잽니다.
   - 아무것도 안 고르면 '표시 안 함'(`teacherIssues: null`)으로 저장되고, 문제 비교에서 빠집니다.
3. 아래 '모은 채점 표본' 표에서 선생님 점수와 엔진 점수 차이, 선생님이 고른 문제를 엔진이 찾았는지(빨강 '놓침', 회색 '+'는 엔진만 짚음)를 봅니다.
4. '표본 내려받기'로 받은 파일을 `test/samples/`에 넣고 `npm test`를 돌리면 차이를 검사합니다.
5. 교사 점수와 판정 기준이 서로 다르다고 확인한 표본에는 `"disputed": "사유"`를 적습니다. 지우지 않고 남기되 검사에서는 뺍니다.

## 학생·교사 글씨 모으기와 개발자 채점 (서버)
- 첫 화면에서 **누가 쓰나요?**를 고릅니다. 실명 입력칸은 없습니다.
  - 학생: `초-3-01`처럼 학교급(초·중·고·전공과)-학년-번호
  - 교사: `교사-이름 또는 번호` (예: `교사-01`). 교사는 쓰고 바로 표본 점수·문제를 붙일 수 있고, 서버에도 같이 저장됩니다.
  - '저장하지 않고 둘러보기'는 서버에 보내지 않습니다.
- 다 쓴 글씨는 획 좌표와 **쓴 시각(밀리초)**, 엔진 점수·문제, 엔진 버전과 함께 Supabase(`kyungmin-main-seoul`, 서울)의 `hw_attempts`에 저장됩니다. 인터넷이 끊기면 기기에 모았다가 다시 보냅니다.
- **글씨 채점실** https://hangeul-one.vercel.app/dev (개발자 계정 로그인)
  - 학생이 쓴 순서·빠르기 그대로 다시 보기(0.5~4배, 긴 멈춤 줄이기, 정답 안내선)
  - 개발자 점수 · 보이는 문제 · 기준 메모를 저장. 엔진 점수는 저장한 뒤에 보입니다('엔진 점수 먼저 보기'로 바꿀 수 있음)
  - '채점한 글씨 내려받기'는 `test/samples/` 형식 파일을 만듭니다.
  - **📋 채점 기준**: 교사 표본에서 뽑은 문제별 점수 범위(`demo/rubric.js`)를 펼쳐 두고 봅니다. 문제 버튼을 고르면 그 범위가 바로 보이고, 벗어난 점수를 넣으면 알려 줍니다. 표본이 늘면 `rubric.js`의 숫자를 다시 셉니다.
- 서버 규칙: 학생·교사는 `hw_submit`/`hw_teacher_label` 함수로 보내기만 할 수 있고, 읽기·수정·삭제는 `hw_developers`에 등록된 계정만 됩니다. 작성자 코드 형식과 1분 30개 제한을 서버가 다시 확인합니다. 2년 지난 글씨는 매일 자동 삭제됩니다.

## 배포 (Vercel)
- 주소: https://hangeul-one.vercel.app (`/` 가 연습 화면, `/demo/review.html` 검수표, `/privacy` `/terms`)
