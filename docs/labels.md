# 평가 항목 정의 (2026-11-23)

채점실·연습 화면 표본 칸·도구·테스트가 모두 `src/labels.js` 하나를 씁니다. 이 문서는 그 정의를 사람이 읽기 좋게 옮긴 것입니다.

## 고르는 법
- **문제 없음**: 모양만 보고 점수를 매깁니다.
- **채점 제외**: 낙서·장난·실수로 찍혀 평가할 수 없는 글씨입니다. 점수 없이 저장하고, 엔진 학습과 기준표에서 뺍니다.
- 문제가 있으면 아래 11개 중에서 **보이는 것을 모두** 고릅니다.
- **살짝 / 뚜렷**: 넘어감·안 닿음·획 모양·크기만 정도를 고릅니다. 누를 때마다 살짝 → 뚜렷 → 해제입니다.
- **★ 먼저 말할 것**: 학생에게 할 말은 따로 고르지 않습니다. 고른 항목 중 표에서 위에 있는 것을 먼저 말합니다. 2개 이상 골랐을 때만 ★로 바꿀 수 있습니다.
- **칭찬**은 앱이 정합니다(점수와 지난 글씨와 비교).

## 11개 항목 (위일수록 먼저 말함)

| 갈래 | 항목 | 정의 | 정도 | 엔진 코드 | 학생에게 |
|---|---|---|---|---|---|
| 글자를 아는가 (배워야 할 오류) | 다른 글자 | 다른 글자로 읽힌다 | | WRONG_CHAR | 다른 글자처럼 보여요. 시범을 보고 다시 써 봐요. |
| | 획 수 | 획이 빠지거나 더 있다(덧그림, 다른 꼴 포함) | | MISSING_STROKE, EXTRA_STROKE, ALT_FORM | 빠진 획(더 그은 획)이 있어요. |
| | 획순 | 그은 차례가 다르다 | | WRONG_ORDER | 획순이 달라요. 시범을 보고 따라 써요. |
| | 방향 | 반대쪽 끝에서 시작했다(시작점이 다른 것 포함) | | WRONG_DIRECTION | 반대로 그었어요. 시작점에서 시작해요. |
| 획을 바르게 긋는가 (운동 조절) | 끊어 씀 | 한 획을 펜을 떼었다가 이어 썼다 | | STROKE_SPLIT | 끊지 말고 이어서 쓰세요. |
| | 이어 씀 | 여러 획을 한 번에 그었다 | | STROKES_JOINED | 이어 쓰지 말고, 획을 나눠서 써요. |
| | 넘어감 | 닿아서 멈출 곳을 지나쳤다 | 살짝·뚜렷 | OVERSHOOT | 닿는 곳에서 멈춰요. |
| | 안 닿음 | 닿아야 할 곳에 못 닿았다 | 살짝·뚜렷 | GAP | 획이 닿을 때까지 그어요. |
| 모양 (운동 조절) | 획 모양 | 획의 길이·기울기·곧기가 안내선과 다르다 | 살짝·뚜렷 | SHAPE | 안내선에 맞춰 다시 써 봐요. |
| 자리·크기 (운동 조절) | 크기 | 너무 작거나 크다(칸 밖으로 나간 것 포함) | 살짝·뚜렷 | TOO_SMALL, TOO_BIG | 알맞은 크기로 써요. |
| | 치우침 | 칸 한쪽으로 몰렸다 | | OFF_CENTER | 칸 가운데에 써요. |

**획 모양 세부 이유**(선택): 길이 · 기울기 · 떨림 · 꺾임 · 간격. 점수에는 쓰지 않고, 엔진이 세부 피드백을 배울 때 씁니다.

## 점수와의 관계
점수 범위는 `demo/rubric.js`의 기준표가 정합니다. 여러 항목을 골랐으면 **점수 범위가 가장 낮은 줄**이 점수를 정합니다(피드백 순서와는 따로).

## 저장 형식 (`dev_issues`, 표본의 `teacherIssues`)
- `'OVERSHOOT'` 항목(정도가 있으면 살짝), `'OVERSHOOT!'` 뚜렷, `'SHAPE.SLANT'` 세부 이유
- `[]` 문제 없음, `['EXCLUDE']` 채점 제외, `null` 표시 안 함
- `dev_feedback`: ★로 고른 항목 코드(없으면 null)

## 예전 표시 옮기기 (2026-11-23 이전)
문제 버튼 14개·피드백 상황 27개로 남긴 표시는 `migrateLabels`/`migrateFeedback`이 읽을 때 바꿉니다.
MISSING_STROKE·EXTRA_STROKE·ALT_FORM·RETRACE → 획 수, START_POINT → 방향, TOO_SMALL·TOO_BIG·OUT_OF_BOX → 크기,
LENGTH·SLANT·WOBBLY·NO_STOP·SPACING·TOO_FAST → 획 모양 세부, SCRIBBLE·EMPTY → 채점 제외, PRAISE·IMPROVED·TRY_AGAIN → 버림.
