# 쓰기 준비(선 긋기·형태 구성 21종) 구현 기록

근거: 「쓰기 준비 기술 학습 콘텐츠 개발 인계서」(05~25번). 번호·활동명·순서·영역은 인계서 그대로다.
인계서 8절 지시에 따라, 확정되지 않은 것은 임의로 확정하지 않고 아래에 **구현 가정**으로 적는다.

## 파일
- `src/prewrite.js`: 21종 모양 데이터(인계서 SVG 경로), 경로 → 획 변환, 점 잇기 지점, 관찰값·별 계산. 한글 채점 엔진(`src/engine.js`)과 분리
- `demo/prep.js`: 연습 화면의 '쓰기 준비' 탭(활동지, 4걸음, 데려다주기 캐릭터, 그리는 법)
- 모양 데이터와 그리는 방식을 나눴다: 같은 경로로 통로·점선·점 잇기·시범을 그린다

## 구현 가정 (바꿀 수 있음)
| 항목 | 인계서 | 지금 구현 |
|---|---|---|
| 지원 단계 | 8가지 | 학생 화면 4걸음: ① 통로 안에서 ② 점선 따라 ③ 점 잇기 ④ 보고 그리기. 통로 넓게/좁게, 점선 촘촘/성기게는 ⚙ 설정. '실선 따라', '기억하여 그리기'는 2차 |
| 여러 M 경로 | 별도 획 또는 별도 문항 | 한 활동지 안의 여러 획으로 둔다(예: 05는 세로선 3개를 한 장에) |
| 획 방향 | 정답으로 보지 않음 | 어느 끝에서 시작해도 같게 본다. 데려다주기 캐릭터도 반대쪽 끝에서 시작하면 그쪽에서 출발 |
| 관찰값 | 형태 정확성·경로 이탈·연결성·독립성 | 덮은 비율, 허용 폭 밖 선의 비율, 끝점·닫힘, 걸음(①~④) |
| 평가 기준·가중치 | 확정하지 않음 | 별 3개: 덮은 비율 85% 이상 + 이탈 20% 이하 + 연결됨, 별 2개: 60% 이상 + 40% 이하, 그 외 1개 (`STAR_RULES`, 임시). 참고 점수 = 60%×덮은 비율 + 40%×(1−이탈), 선생님 '자세히'에만 |
| 허용 폭(활동지 높이 기준) | – | 통로 넓게 0.085 / 좁게 0.055, 점선·점 잇기 0.09, 보고 그리기 0.11(쓴 선의 테두리를 모양에 맞춘 뒤 견줌) |
| 걸음 올리기 | 학생별 조정 | 별 3개면 다음 걸음, ④를 마치면 다음 활동(‘S를 받으면 다음 글자로’ 설정을 따름). 걸음 단추로 언제든 앞뒤로 옮길 수 있음 |
| 동기유발 | – | 데려다주기: 시작점 캐릭터(토끼·꿀벌·자동차·고양이), 끝점 목표(당근·꽃·집·물고기). 따라 그린 비율이 75%를 넘고 끝점에 닿아야 '도착'. 모두 도착하면 0.7초 뒤 스스로 확인. 캐릭터는 직접 그린 그림(기기마다 다른 이모지 대신), ⚙ 설정에서 끄면 초록 점·빨간 깃발 |
| 저장 | 확정하지 않음 | 다 그리면 서버 `hw_attempts`에 저장(2026-11-26 운영자 승인): 글자 칸 `P05`~`P25`, 걸음 `prep_step`(1~4), `engine_score`=참고 점수, `engine_issues`=관찰 코드(NOT_CONNECTED·STRAY·LOW_COVER), `engine_version`=`prep-0.1`. 둘러보기는 보내지 않음. 진행(몇 걸음까지)은 이 기기에도 쓰는 사람별로 기억 |

## 채점실·반영
- 채점실은 쓰기 준비 글씨를 가로 활동지로 다시 보여 주고, 앱의 별·관찰값과 내 점수를 견준다. 평가 항목(한글용)은 숨긴다
- 매일 반영은 쓰기 준비 채점을 `test/server-samples/prewrite.json`에 따로 모은다(한글 엔진 검사·기준표와 섞지 않음). 별 기준을 정할 근거로 쓴다

## 검수
- 21종 모두 활동지 안에 들어가고, 정확히 따라 그리면 정방향·반대 방향 모두 별 3개(검사 `npm test`)
- 보고 그리기는 자리·크기가 달라도 같은 모양이면 별 3개, 반만 그린 원은 별 3개가 아님
- 화면: 컴퓨터·아이패드·휴대폰 크기에서 가로 넘침 없음. 활동지는 가로 760px까지, 비율 118:58 유지

## 범위 밖
미로·대칭 그림·자모·낱말 쓰기(인계서 7절). 1~2단계(잡기·끼적이기)는 앱에서 다루지 않는다(운영자 결정).
